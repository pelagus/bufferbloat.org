# bufferbloat.org

A browser-based bufferbloat test focused on responsiveness under load.

Most speed tests measure bandwidth. bufferbloat.org measures whether your connection still feels responsive while downloads and uploads are active.

## Live site

https://bufferbloat.org

## Features

- Quiet-line latency measurement
- Download latency under load
- Upload latency under load
- Throughput measurement
- Responsiveness grading
- Mobile-friendly live instrumentation UI
- Browser-based testing
- Open source

## Tech stack

- Next.js App Router
- TypeScript
- Vercel
- Cloudflare
- CSS modularized by concern
